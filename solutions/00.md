# Solution 00

Dial9 sees Axum's connection tasks through Tokio's runtime hooks, but ordinary
`axum::serve` does not give it full task identity and wake causality.

The patch replaces `axum::serve` with Dial9's Axum adapter and uses the current
`Dial9TokioHandle` to spawn connection and Hyper tasks.
Hotlap results shouldn't change meaningfully, the improvement is richer task information in the viewer.

```bash
git apply solutions/00.patch
```
