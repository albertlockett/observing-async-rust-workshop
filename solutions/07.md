# Solution 07

The service enables `TRACE` for the entire application. Every event payload is
therefore formatted, JSON-encoded again by the tracing subscriber, and written
to `workshop.log` synchronously from the request poll.

The patch restores the production `info` filter. The trace statement can stay
for targeted debugging; while disabled, tracing rejects it at the callsite
before constructing its fields.

```bash
git apply solutions/07.patch
cargo hotlap --exercise 07
```

The logging stack should disappear from the flamegraph and `workshop.log`
should stop growing once per request. In the prepared 10k req/s runs, p99 moves
from 4.3 ms to 3.4 ms and the 15-second log shrinks from 164 MB to under 1 KB.
