# Prepared solutions

Each numbered solution has a short explanation. Code exercises also have a
patch; exercise 06 has an operational fix instead. Read the Markdown file
first, then apply patches from this repository root:

```bash
git apply solutions/03.patch
```

Exercise 02 has two stages: `02-instrumentation.patch` leaves the bug
in place for diagnosis, then `02-fix.patch` corrects it.
