# Solution 05

International searches take a Unicode-validation path that recompiles the same
regular expression on every request. The on-CPU flamegraph attributes repeated
parsing, compilation, table building, and allocation to `valid_search_query`.

The patch stores the compiled Unicode regex in `LazyLock` and reuses it. One
initial compilation is expected; repeated compiler stacks should disappear.

```bash
git apply solutions/05.patch
cargo hotlap --exercise 05 --staged
```

In the prepared runs, incident p99 falls from 24.9 ms to 4.4 ms and the
repeated regex compiler stack disappears.
